# Aplicação PHP + SQLite

A documentação de instalação, configuração, publicação e testes fica no
[README principal](../README.md).

- Modelo de configuração: [config.example.php](config.example.php).
- Raiz pública: `public/`.
- Guia para usuários: `public/guia.php`, acessível pelo navegador com o PHP em execução.
- Demonstração: `php painel_php/seed-demo.php --demo`, a partir da raiz, somente em banco vazio.
- Código compartilhado do front-end: `../site/`; mantenha essa pasta ao publicar.

Nunca envie `config.php`, bancos ou backups ao GitHub.
